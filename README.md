# Student Management System in C

## About the Project
This project is developed as part of the CodeAlpha Internship. It is a menu-driven C program designed to store and display student information using structures.

## Features
- Enter details of 5 students.
- Store student roll number, name, age, and marks.
- Display the details of all entered students.
- Menu-driven interface.
- Option to exit the program.

## Technologies Used
- C Programming
- GCC Compiler

## Concepts Used
- Structures
- Array of Structures
- Functions
- For Loops
- Do-While Loop
- Switch-Case
- Conditional Statements

## How to Run

1. Download or clone this repository.
2. Open the project folder in the terminal.
3. Compile the program:

```bash
gcc student_management.c -o student_management
```

4. Run the program:

```bash
./student_management
```
